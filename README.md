# Weekly Report Generator & Team Dashboard

A full-stack web application that allows team members to create and submit structured weekly reports and enables managers to review, approve, request corrections, and analyze team performance.

## Technology Stack

### Frontend

- Next.js
- TypeScript
- Tailwind CSS
- shadcn/ui
- React Hook Form
- Zod
- Recharts

### Backend

- NestJS
- TypeScript
- Prisma ORM
- PostgreSQL
- JWT Authentication
- Swagger
- Jest
- Supertest
